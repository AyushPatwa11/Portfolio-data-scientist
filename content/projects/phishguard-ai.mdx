### System Overview

**PhishGuard AI** provides transparent, explainable phishing detection for emails and URLs:

- **Explainable Predictions (XAI)**: Visual explanations of model decisions for security awareness.
- **Threat Intelligence**: IP geolocation, domain reputation analysis, and threat visualization.
- **REST API & Dashboard**: Interactive interface for instant phishing risk evaluation.
