### System Overview

**Scantinel** is a comprehensive web vulnerability assessment platform built for developers and security auditors:

- **10 Assessment Phases**: Header analysis, SSL validation, port scanning, exposed resource detection, and OWASP Top 10 checks.
- **Real-Time SSE Streaming**: Live progress feedback during active security scans.
- **AI Remediation**: Automated risk grading, AI security recommendations, and exportable PDF/CSV audit reports.
